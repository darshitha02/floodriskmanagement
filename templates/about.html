About FloodRiskAI

Built for DataQuest 2026 · Disaster Management Analytics & Intelligence System.

Platform Architecture & Capabilities

FloodRiskAI is an end-to-end disaster management platform designed to bridge historical hydrological telemetry with real-time AI predictions, geospatial risk mapping, and emergency response playbooks.

Level 1 · Analytics
Geospatial Analytics

Historical flood event frequency, state-level risk heatmaps, cause distributions, and live river telemetry stream.

Level 2 · AI Prediction
Multi-Model Machine Learning

Ensemble of Random Forest, Support Vector Machine (SVM), and Logistic Regression with local SHAP feature attributions.

Level 3 · Intelligence
Scenario & Emergency Response

Climate stress-test simulator, river discharge sensitivity curves, and automated disaster response playbook dispatch.

Underlying Datasets
  • Gauge Flood Events Dataset (`floodevents_indofloods.csv`): Contains 4,548 gauge-level hydrological flood events with peak discharge (cumec), flood volume, event duration, time to peak, recession time, and severity classifications.
  • India Flood Inventory Dataset (`India_Flood_Inventory_v3.csv`): Contains 6,876 historical flood records spanning Indian states and districts, detailing main causes, displaced populations, and fatalities.
Key Project Highlights
  • Ensemble ML Accuracy: 82.5% test accuracy with 0.879 ROC-AUC.
  • SHAP Feature Explainability: Local waterfall feature attributions for every prediction.
  • Geospatial GIS Engine: Interactive India flood heatmaps and live river gauge monitoring.
  • OpenAPI REST Hub: Full developer API with batch prediction & PDF report exports.
